# Customer Support & Query Resolution System

A portfolio project demonstrating a spreadsheet-based workflow relevant to customer operations and office administration.

## Project files
- [`Customer_Support_Query_Resolution.xlsx`](Customer_Support_Query_Resolution.xlsx) — Excel workbook with fictional sample records, tracking fields, formulas, and a dashboard.
- [`Project_Case_Study.md`](Project_Case_Study.md) — problem, workflow, metrics, and limitations.
- [`Portfolio_Entry.md`](Portfolio_Entry.md) — resume-ready project description.
- [`index.html`](index.html) — project landing page.

## Metrics included
Total tickets, open/in-progress tickets, urgent tickets, resolved/closed tickets, resolution rate, average resolution time, and average customer satisfaction score (CSAT).

## Scope and limitations
All 15 ticket records are fictional. Google Forms and Freshdesk are possible future extensions only; neither is connected. Due dates are illustrative, not a real service-level agreement (SLA).
